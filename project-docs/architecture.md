# Architecture — arcade-library

A static site. There is no server code, no database, no account and no build on the host: the
compiled `.wasm`, the base64 copy inside each widget and the course HTML are committed, and
Vercel serves the repo root as-is (`vercel.json`: `framework: null`, `outputDirectory: "."`).
Engineering detail lives in `CONTRIBUTING.md`; this file is the map.

## Hosts
| Host | Serves | Repo |
|---|---|---|
| `https://library.gautamgoklani.com` | This repo | `arcade-library` |
| `https://www.gautamgoklani.com` | The portfolio. Footer links here; `/arcade`, `/arcade/:slug`, `/library` 308 to the hub | `portfolio` (`next.config.ts`, `SITE.libraryUrl`) |

## Routes
| Path | What it is |
|---|---|
| `/` (`index.html`) | Hub: game cards with best scores, course highlights, build steps |
| `/games/<slug>/index.html` | A game's standalone page: the hosting shell (bar, frame) around the widget |
| `/games/<slug>/demo.html` | Minimal integration example for embedders |
| `/docs/index.html`, `/docs/<chapter>.html` | The course, generated by `scripts/build-docs.mjs` |
| `/docs/reference/` | The original project documents |

## Layers
| Layer | Files | Owns |
|---|---|---|
| Engine | `games/<slug>/game.wat` → `game.wasm` | All game state and rules. Exposes `init`, `set_input`, `step`, `get_*` and event counters |
| Widget | `games/<slug>/<slug>.js`, `<slug>.css` | Input, drawing, sound. `<Name>.mount(el, opts)` → `{ restart, destroy, getState }`. CSS under `.<prefix>-root` |
| Page shell (hosting) | `games/<slug>/index.html` | Sizes the widget to the window, the `arcade-bar` (back link, full screen), the frame, best-score watching |
| Hub (hosting) | `index.html`, `hiscores.js` | Design tokens, theme, cards, best scores from `localStorage` (`arcade-library:best:<key>`) |
| Tooling | `scripts/build.mjs`, `build-docs.mjs`, `check-layout.mjs`, `serve.mjs` | Build and the `npm run check` guard |

## Data
No server-side data. The browser keeps two things in `localStorage`, and both fail safe when
storage is blocked: best scores (`hiscores.js`) and the hub theme (`theme`).

## Decisions
- The hub borrows the portfolio's tokens by copying them (2026-10-29). The two repos share no
  package, and one page isn't worth one.
- Game pages are dark-only and keep each game's palette. Only the frame is modern.
- The full-screen button fullscreens the whole page, not the canvas, so the HUD and touch
  controls come along.

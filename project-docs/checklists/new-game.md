# New Game Checklist — arcade-library

Every step of `CONTRIBUTING.md` "Adding a game", plus:

- [ ] The page shell is copied from an existing one, including the `.arcade-bar`, the frame CSS
      and the full-screen script, with the title changed.
- [ ] The `--bar` allowance is in the shell's height calc.
- [ ] The hub card has a logo on a plate, tags, and an `href` of `games/<slug>/index.html` (the
      best-score script reads the slug from it).
- [ ] TC-SHELL-001 passes for the new game.

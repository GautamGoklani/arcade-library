Arcade Library

Arcade games with no engine underneath them.

Six browser games whose entire simulation — physics, enemy AI, bullet pools, collisions, territory capture, fuel and cargo, a procedurally generated board — is hand-written WebAssembly Text. No game framework, no compiler front-end, no runtime dependency. JavaScript forwards input and draws what it reads back out of linear memory, and that is all it does.

Play

Pixel Wave

A retro wave shooter. The swarm patrols the upper half of the arena, asteroids fall, and every cleared level adds one more enemy.

3.5 KB engine33 enemiestouch + keyboard

Grid Breaker

Brick-breaking where the brick layout, the ball physics and the power-up drops all live in the engine. The paddle follows the pointer, or a stick on touch.

4.4 KB enginepower-upstouch + keyboard

Worm Chase

Leave your territory, loop back, and everything the loop sealed off becomes yours. A flood fill decides what counts as enclosed.

3.8 KB engineno importstouch + keyboard

Asteroid Miner

Break rocks into smaller rocks, fill the hold, and fly it home before the tank runs dry. Drawn at 320x240 with scanlines, on purpose.

4.2 KB enginefuel + cargotouch + keyboard

Sector Defense

Hold a line against attackers that each pick their own path. A shield that only recovers once the shooting stops, and a combo that decays.

3.6 KB engineno importstouch + keyboard

Circuit Runner

Six traces, components coming at you, and current draining the whole time. Nothing to shoot — the only verb is which trace you are on.

3.0 KB engineendlesstouch + keyboard

Build from source

git clone https://github.com/GautamGoklani/arcade-library
cd arcade-library
npm install          # wabt, the WebAssembly Binary Toolkit
npm run build        # every game.wat → game.wasm
npm run serve        # http://localhost:8080

The compiled .wasm files are committed, so a fresh checkout is playable without installing anything. npm run check verifies they still match their sources.
